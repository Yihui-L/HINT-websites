# 两种边界与散度控制

![矩形边界与第一壁边界的对比示意](assets/boundaries.png)

图是任意 R–Z 截面的定性示意，不是实际 NCSX 几何。黄色区域在 debug 中仍有磁场/速度演化，在 wall 中不是物理演化域。

## 共同物理约定

静止理想导体要求边界法向磁通不随时间改变，不一般要求总 Bn=0。线圈背景场 B₀ 已穿透壁，且固定。响应场满足：

$$\mathbf n\cdot\mathbf B_1(\tau)=\mathbf n\cdot\mathbf B_{1,\rm initial},\quad \mathbf v|_S=0.$$

zero 起点的右端为 0；vmec 起点通常非零。两者是不同的冻结磁通初值，不能比较时忽略这一约束差异。总法向场为 B₀n 加该冻结值。

理想壁、真空开放边界和不导电材料不是同一数学条件。真实不导电外域通常需要内外磁场匹配/势场求解，不能简单以局部 Bn=0 代替。本版本没有有限电阻壁的表面电流演化模型。

## debug：矩形域

R–Z 外边界两层保护节点施加冻结响应法向场、零速度；切向分量按层使用二阶/四阶外推。环向周期。真实壁限制压力和源电流，但壁外至矩形边界仍演化响应场和速度，采用 eta1（0 表示继承 eta0）。这不是完整无质量真空 Maxwell 求解。

保证兼容性的关键在于**取旋度之前**约束切向感应通量。这样离散 curl 更新本身满足矩形法向增量要求，不再先形成无散增量、随后用不相容的法向硬截断破坏它。

散度扩散为 `kappa*grad(div B1)`，边界标量处理与矩形算子一致；可选状态投影默认关闭，具有有限值/不恶化保护。固定 B₀ 不随这些清理改变。

矩形边界离等离子体太近时会强烈限制响应场；“边界设置与原版相同”不能保证它是可信的无限空间自由边界。需以域大小/边界影响的收敛性判断，这不在本次文档构建中做算例测试。

## wall：扭曲第一壁

壁由 signed distance、法向与插值构成浸入式延拓 E；跨周期处理包含柱坐标基矢旋转。全状态使用仿射延拓以维持非零初始法向参考，增量和伴随使用齐次延拓，不能混淆。

实际散度算子含壁延拓，D†是带 R 体积权重的对应伴随。数值散度扩散采用：

$$\mathcal Q_{\rm div}=-\kappa D^\dagger D\mathbf B_1.$$

它具有半离散能量非增性质；显式时间积分仍须满足稳定性限制。不能把算子里的负号误换成笛卡尔梯度符号后随意套用。

每个 RKG 阶段，对感应旋度增量 q 作齐次壁约束和最小改动投影：

$$q_c=M_0(q-D^\dagger\psi),\qquad DD^\dagger\psi=Dq.$$

这里 M₀表示齐次边界闭合；程序使用相容的复合算子。此步骤独立于用户可选全状态投影，**`divergence_projection_iterations=0` 不能关闭它**。阶段求解上限为配置值、400 和网格相关上限中的最大值；容差兼顾相对残差与机器舍入尺度，不允许明显不满足约束的增量静默进入后续步骤。

可选状态 PCG 在配置间隔及 Step-B 末尾修正剩余散度，保留有效改善的解。投影不是新的物理驱动，但若每步修正很大，就说明原始离散更新/网格精度不能被忽略，不能只看投影后残差小。

## 精度边界

wall 的每阶段求解意味着它在同网格下可能明显慢于 debug。这不是遗漏了一个 GPU 开关。更高阶几何、拟合网格或兼容有限元可能改善边界表达，但当前代码使用的是柱坐标规则网格与浸入边界，不宣称具备有限元精确曲面拟合。
