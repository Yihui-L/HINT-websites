## 特别核对的接口

- 主结果 `equilibrium/B` 是 SI 总场；B₁需减内嵌背景场，s 字段为 `norm_s`。
- 时间换算字段为 `alfven_time_reference`，不是内部 Python 属性名 `alfven_time_s`。
- `profiles.source=input` 时的 `profiles.current` 应按 lambda 形状解释，不是 jcurv / I / dI/ds。
- CLI 磁面量 `surface_circuits` 是完整环向圈；Notebook `crossings` 为场周期回归次数。
- wall 每 RKG 阶段的强制约束与可选全状态投影不同，后者为 0 不会关闭前者。
