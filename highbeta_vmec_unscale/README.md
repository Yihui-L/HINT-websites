## 图片内容与统计定义

全部图见 [figures/](figures/README.md)，只保存 PNG，不生成或发布新的后处理 `.nc`、`.npz` 或 `.csv`。
原有 84 张图片调用 `hint_debug_plotting.HintPlots`，传入本次结果及实际使用的 wout，输出分辨率 300 dpi。新增初始化总场庞加莱为 320 dpi；现共有 85 张 PNG。

- 截面取 φ=0°、30°、60°，即半个场周期的两端和中点，纵向排列。
  叠加真实壁、矩形计算域、VMEC 磁轴和 s=0.25、0.5、0.75、1 磁面；s=1 为初始 LCFS。
  只在 API 支持相同物理量比较时叠加 VMEC 等值线，不伪造 VMEC 的流速或力残差参考。
- 剖面包含压强、环向电流密度、流速、力残差、局域相对力残差和总场强；横坐标包括 s、ρ、R、Z、φ。
  s/ρ 剖面是各截面内按**演化后的 HINT 标签**分箱的面积统计，不是严格磁面平均，也不是初始 VMEC 磁通平均。
  R 曲线取 Z=0；Z 曲线取 R=1.57 m；φ 曲线取 R=1.57 m、Z=0。
- 环向电流密度是点值 `J1_phi`，单位 A/m²，不是 VMEC 的 `jcurv` 或 `dI/ds`。
  累计电流图使用阈值内的 `∫J1_phi dR dZ`，不假设演化标签面仍是严格磁面。
- 相对力残差采用 `|J1×B−∇p| / max(|J1×B|, |∇p|)`，两项都接近数值零时屏蔽，
  不用一个任意小分母放大噪声。它是局部力不平衡比例，与主程序的归一化力 RMS 不是同一种量。
- checkpoint 演化曲线分别统计第一壁内、以及第一壁内 `0≤s<1` 的区域。
  体平均和体 RMS 使用柱坐标体元的 R 权重；最大值不加权。区域随 s 演化可以改变。
- `convergence_stepb_*` 使用各外迭代最后一个内部步的**已存归一化诊断**；
  `convergence_response_divergence_si` 使用完整保存态在物理矩形域内的**算术 RMS/最大绝对值**，单位 T/m。
  两组量的归一化、采样时刻和舍入误差不同，不能直接混用。
- 速度变化率根据相邻保存态和换算后的弛豫时间计算，不是对实验时间的真实加速度。

## 第 100 步庞加莱与旋转变换

第 100 步庞加莱使用该步总场 `B0+B1`，在三个截面分别布置覆盖较大区域的二维种子、Z=−0.08/0/0.08 m
径向种子及外侧加密网格。仅启动有效的壁内种子；每条线最多追踪 600 个场周期，
每周期 128 个输出子步，相对/绝对积分容差 `1e-8/1e-10`。
全图和外侧细节图使用同一批轨迹。空白或提前出壁不是人为补造的磁面。

旋转变换扫描初始 VMEC **s=0.0001–0.9999**：内部使用 161 个等间隔点，
轴附近和边缘分别增加对数加密点，去重后每个截面共 **191 个起点**。
每个 s 在每个 φ 截面使用 **一个 VMEC θ=0 起点**；三个截面独立计算，不将三个起点的 iota 平均。

计算先寻找第 100 步总磁场的磁轴，再沿磁力线累计相对该磁轴的连续极向绕转角。
`iota_geometric = ΣΔθ / Δφ`；最后按 wout 的极向方向和坐标绕转约定转换成 VMEC iota 约定。
这里的平均是**沿同一条磁力线的长程绕转平均**，不是同一 s 上多个起点的平均。
每条线追踪 512 个场周期（nfp=3，约 170.7 个完整环向圈），每周期 128 个子步。
前后半段 iota 差要求不超过 0.002，另有截面分辨诊断阈值 0.02；后者不是严格存在磁面的证明。

`profile_rotational_transform_initial_vmec_s.png` 特别保留**初始 VMEC 起点 s** 横坐标；
另有以 HINT 演化标签 s/ρ 和起点 R/Z 为横坐标的图。
初始 VMEC 磁面不一定与演化后的磁结构重合，特别是在磁岛或随机区；
有限但未通过收敛/截面分辨检查的结果用单独标记，不当作可靠磁面 iota。
失败或未解析轨迹不插值填补，s=0 的轴上几何极角本身也不用于直接绕转追踪。

本次 φ=0°/30°/60° 分别得到 90/58/71 个有限绕转估计，
其中仅 **24/34/53** 个同时通过当前的绕转收敛和截面分辨检查。
因此，“初始 s 范围已加密采样”不等于“整个范围都有可靠的磁面 iota”。
磁轴固定点满足程序的网格相关容差，但未达到更严格的非线性容差，程序已输出警告；
对应闭合误差约 `8.70e-8 / 5.43e-8 / 7.77e-8 m`。本次未放宽追踪阈值来增加通过数量。

## 重新运行与续算注意事项

安装上述源码提交的 HINT-debug，补齐缺省的 wout/mgrid 后，可按主程序 TOML 重新初始化。
这会产生新的结果，不能在保留重要旧结果的输出路径上直接覆盖运行。
follow 示例需要已有完整 `run/hint_debug_ncsx_vmec.nc`；其 `outer_steps=200` 是**额外**步数，
不是绝对终点 200。follow 从结果文件恢复准备数据和演化状态，不需要重新读取外部 wout/mgrid/壁文本；
不得与正在写同一文件的主程序同时运行。

不代表本次密集庞加莱和 iota 扫描的采样量。当前主程序结果仍保留在远程，未下载到本地。
