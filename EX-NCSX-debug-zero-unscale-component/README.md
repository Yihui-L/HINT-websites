## 诊断说明

初始连续线圈源表达式AD、实际分量插值器AD、HINT网格FD4必须区分。初始响应场恒零，没有virtual-casing或LCFS拼接。低FD4响应散度不保证分量插值场无散；源AD低也不等于插值器AD低。末态高精度求导核验针对实际插值器，不是重新得到一个末态解析源场。细节、采样数、单位、归一化和哈希见Documents/docs-data。
